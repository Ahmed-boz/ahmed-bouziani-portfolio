# Portfolio BTS SIO SISR

Reproduction statique du portfolio public d'Ahmed Bouziani, préparée pour GitHub Pages. Le site garde le même contenu, les mêmes styles, le schéma réseau SVG, les logos, les deux PDF et le terminal interactif.

## Publier avec GitHub Pages

1. Créer un dépôt GitHub, par exemple `ahmed-bouziani-portfolio`.
2. Importer tous les fichiers de ce dossier à la racine de la branche `main`.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, la branche `main` et le dossier `/ (root)`, puis enregistrer.
4. Après la publication, le site sera disponible à `https://Ahmed-boz.github.io/ahmed-bouziani-portfolio/`.

Le site ne nécessite ni compilation ni dépendances. `index.html` est le point d'entrée. Les seules ressources hébergées ailleurs sont les polices Google Fonts ; les images et les PDF sont locaux au dépôt.
